Comando para compilar el prorama 

g++ Caraya_lab8.cpp -o lab8

----------------------------------

Para ejecutar el programa hay que ingresar 3 parametros 

./lab8 valor1 valor2 valor3

valor1 = Numero para definir el tamaño del arreglo.

valor2 = Es para mostrar o no los elementos del arreglo ( T o F ), T para ver el arreglo y F para no verlo.

valor3 = Es para definir el formato en el que se entrega el tiempo de ejecucion ( S o M ), S para mostrar el tiempo en Segundos y M para mostrar en Milisegundos.
